探索方法：
- capabilities.remote_shell=true 时，可围绕已认证的 SSH RUNTIME_SURFACE 提议正常基线命令与获授权的最小输入实验，由 Worker 通过 ssh_exec 执行。SSH 只是访问通道，不因目标没有 Web 页面或前后端分类而跳过。宿主本机 shell 始终不可用。仅限用户授权的远端服务、目录和测试数据，不提议跳板、隧道、后台驻留或从远端访问其他未授权目标。
- SSH 登录成功只证明可访问；特权账号直接执行命令不证明应用存在命令注入或提权漏洞。证明必须从应用真实入口触发并完成反证。
- 从正常页面与网络样本关联 UI 动作、路由、方法和参数结构，优先验证角色/对象边界及业务状态。
- 授权两身份时对照所有者正常访问、非所有者访问和不存在对象响应；不要读取真实用户数据。200 或不同响应本身不证明越权。
- 输入实验仅在 allowed_actions 包含 test_input 时提议，使用无害唯一标记。XSS 必须经应用输入并刷新/重访，跨用户影响须独立授权身份；DOM 注入和模拟内容不是证据。
- 不提议删除、覆盖、重置、上传、批量写入、资源耗尽、未授权命令、凭证读取或外联。当前自主探索只开放正常访问与已授权的最小输入实验；不能清理的存储输入不执行。
- 所有 SOURCE 与 RUNTIME 来源保持分离。仅名称或路径相似不证明部署与冻结源码一致；部署未知就保留 UNKNOWN。
