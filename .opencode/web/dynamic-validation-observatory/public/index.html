  1. 选择一条验证记录，点击“导出 Bruno 集合（JSON）”。

BOUNDARIES

平台安全边界

  • 服务仅监听 localhost / 127.0.0.1 / [::1]。
  • 审计项目由操作员指定工作台所在机器上的绝对目录，并在服务端规范化、校验和持久登记。
  • 目标源码目录与工作台 OpenCode Agent/MCP 配置相互隔离。
  • OpenCode 通过参数数组与固定 orchestrator prompt 启动，shell=false。
  • 默认拒绝脏工作树和未 checkout 的目标 ref。
  • 新建任务按所选参与方式、动作和总预算执行环境接触、中期测试与按需确认；未提供有效环境时自动跳过。贯穿式测试由用户确认环境并授权目标，不根据公网或内网分类拒绝。人工补充验证需逐次授权并保存独立结果，沿用原有 localhost 契约。

目录不要求 Git。任务实际启动前会生成范围清单与逐文件摘要；多范围对象会保存，但在跨范围关联流水线启用前不能启动。

启用环境开关即确认目标为你有权测试的环境，并授权所选参与方式与动作。你填写的整段内容会作为私有 prompt 完整交给 Agent，不要求固定账号字段、分行格式或 JSON。Agent 先理解环境，再进行必要登录和测试；确实缺少信息时说明具体缺口，静态审计继续。未启用或未填写时自动跳过；浏览器只访问从原文确认的授权目标。新建重试会回填原说明供你修改；环境原文和凭据不在任务列表、日志或报告中回显。动态支持证据仍进入独立三方复核。
